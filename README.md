# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing Human Resources (HR) data using Microsoft Power BI. The main objective is to transform raw employee data into meaningful insights through interactive visualizations and key performance indicators (KPIs).

The dashboard provides an overview of workforce distribution, employee attrition, salary analysis, and employee performance across different departments.

## 🎯 Business Objectives

- Analyze employee demographics and workforce distribution.
- Identify employee attrition trends.
- Compare salary levels across departments.
- Evaluate high-performing employees.
- Support data-driven HR decision-making.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization

## 📈 Key Performance Indicators (KPIs)

- Total Employees
- Attrition Rate
- Average Salary
- Employee Distribution by Department
- High Performers by Department
- Departmental Performance Analysis

## 📊 Dashboard Features

- Interactive dashboard design.
- Dynamic slicers for filtering and exploring data.
- Department-level comparisons.
- Employee attrition analysis.
- Salary and performance analysis.
- KPI cards and interactive visualizations.

## 🔍 Key Insights

The dashboard enables users to explore workforce trends, identify differences between departments, and investigate employee attrition and performance patterns.
